# Licence Files

This directory contains the canonical licence texts used across the Anitelos
ecosystem. A licence file being present here does **not** apply it to every file
in this repository. The controlling boundary is declared in
[`../LICENSING.md`](../LICENSING.md), repository-level notices and any more
specific `LICENSE` or SPDX header nearer to the material.

| Identifier | Intended scope |
| :--- | :--- |
| `AGPL-3.0-only` | Anitelos applications, services and reference implementations |
| `Apache-2.0` | Public schemas and protocol definitions intended for broad interoperability |
| `CC-BY-SA-4.0` | Original Commons prose, documentation, diagrams and the future END Theory |

Third-party material retains its own licence. Private user knowledge and
diagnostic content are data belonging to their relevant rights-holders; their
presence in or transmission through Anitelos does not relicense them.

These boundaries are an initial policy and require qualified legal review before
commercial reliance.
